# Local To-Do App with Login

A simple React application built as part of the internship assignment.

## Features

* Login page with validation
* Protected route implementation
* Login persistence using localStorage
* Logout functionality
* Responsive UI design

## Technologies Used

* React
* Vite
* React Router DOM
* CSS
* localStorage

## Installation

Install dependencies:

```bash
npm install
```

Run the project:

```bash
npm run dev
```

Open:

```text
http://localhost:5173
```
